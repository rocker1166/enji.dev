## Delivery: projects, tasks and approvals

Projects run on a 7-phase workflow. Tasks have board, list, calendar and timeline views, plus a review step with an SLA: when a task sits in review too long it gets flagged, and analytics shows the median review time.

Clients approve work from a link, without an account: approve, reject or ask for changes. That public endpoint is rate limited and idempotent, so a double click never creates two approvals.

## Money that adds up

Finance is where bugs cost real money, so I built it to be boring:

- invoice numbers come from a sequence inside the same transaction
- payments are recorded with an idempotency key
- a refund is a reversal row, never a delete
- credit balance is derived from the ledger, never stored
- billing schedules run from a cron worker that is safe to re-run
- invoices render to PDF on the server

## The AI assistant

The assistant answers questions about the agency's own data: who is overloaded, which invoices are overdue, which deals are stuck. It queries through **read-only SQL views on a read-only database pool**, logs every action it takes in a write ledger, is throttled per turn, and fails closed before anything destructive.

## Security

Multi-tenant SaaS lives or dies on tenant isolation. My hardening work included an `ORDER BY` allowlist that closed a SQL injection, RBAC that fails closed for unknown roles, closing a cross-tenant file leak on legacy storage keys, rate-limited auth, email header-injection fixes, and a one-day batch of IDOR and permission fixes across approvals, inbox, webhooks and trash.
